# GrowthPilot Digital — Website

Responsive digital marketing agency website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a web browser.

## Before publishing
- Replace the GrowthPilot Digital brand if you prefer another name.
- Replace `hello@growthpilot.example` with your real email.
- In `script.js`, replace `919000000000` with your WhatsApp number (country code + number, digits only).
- The dashboard numbers are illustrative demo data, not client results.
- The enquiry form opens WhatsApp and does not save submissions.

## Publish online for free with GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open repository Settings → Pages.
4. Choose “Deploy from a branch”, select `main` and `/(root)`, then Save.
5. After deployment, your website will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
